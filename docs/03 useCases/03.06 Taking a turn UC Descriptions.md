# 03.06 Taking a turn UC Descriptions #
## UC-01: Start Game ## 

Primary actor: Player 1 (Initiator) Goal: Initialize the game session and begin gameplay. Preconditions: Two players are connected/matched Trigger: Player 1 and Player 2 selects "Start Game".

Main success scenario:

System initializes the game board/environment.

System assigns starting resources or positions.

System determines the turn order (designating Player 1 as the first active player).

System transitions to the "Take Turn" state.

Postconditions: Game is active; Turn begins.

## UC-02: Take Turn ##

Primary actor: Current Player (Player 1 or Player 2) Goal: Begin the phase where the player can interact with the game. Preconditions: The previous state (Game Start or Previous Player's End Turn) has concluded. Trigger: System passes control to the Current Player.

Main success scenario:

System unlocks interface controls for the Current Player.

System displays valid actions available for this turn.

Player evaluates the game state.

Postconditions: Player is ready to "Make Move".

## UC-03: Make Move ##

Primary actor: Current Player Goal: Execute a specific action to change the game state. Preconditions: It is the player's turn, and at least one valid move is available. Trigger: Player selects a specific action/move.

Main success scenario:

Player inputs the desired move.

System validates that the move is legal according to game rules.

System updates the internal game state (positions, scores, health, etc.).

System reflects changes in the UI for all players.

Postconditions: Game state is updated; progression to "End Turn" is available.

## UC-04: End Turn ## 

Primary actor: Current Player Goal: Finalize the current round of actions and pass control. Preconditions: A move has been executed (or the turn timer has expired). Trigger: Player clicks "End Turn" or system auto-ends turn.

Main success scenario:

System finalizes any end-of-turn effects (buffs, damage, scoring).

System checks for Win/Loss conditions.

If no Game Over condition is met, System passes control to the opposing player (loops back to UC-02: Take Turn).

Postconditions: Current player's control is locked; opposing player becomes the Current Player.

## UC-05: Win Game ##

Primary actor: Winner (Depicted as Player 1 in diagram) Goal: Achieve the victory condition. Preconditions: The "End Turn" check validates that victory criteria are met. Trigger: System detects a winning state after a move.

Main success scenario:

System halts gameplay.

System announces the winner.

System offers options to return to the lobby.

Postconditions: Game session ends; Session is closed.

## UC-06: Lose Game ##

Primary actor: Loser (Depicted as Player 2 in diagram) Goal: Receive game-over notification. Preconditions: The opponent has met the victory condition (or current player met a loss condition). Trigger: System detects a loss state.

Main success scenario:

System halts gameplay.

System announces the defeat.

System offers options to return to the lobby.

Postconditions: Game session ends.
